## Selected Engineering Work

### IncidentGraph — AI Incident Investigation & Reliability Platform

An evidence-driven incident investigation system built around production reliability rather than a chatbot demo.

- Instruments **6 microservices** and includes **36 reproducible fault scenarios**
- Correlates metrics, logs, traces, deployment history, and retrieval evidence
- Durable agent workflows using **LangGraph**
- Hybrid RAG with **PostgreSQL + pgvector + full-text search + reciprocal-rank fusion**
- Evaluation harness covering RCA accuracy, evidence recall, unsupported claims, tool-use correctness, latency and token cost
- **OpenTelemetry, Prometheus, Loki, Tempo** observability stack
- **Docker, Kubernetes, Helm, Terraform** deployment assets
- **81 backend tests**, 80% measured coverage
- Human-approved, allow-listed remediation boundaries
