## Selected Engineering Work

### IncidentGraph — AI Incident Investigation & Reliability Platform

An evidence-driven incident investigation system built around production reliability rather than a chatbot demo.

- Instruments **6 microservices** and includes **36 reproducible fault scenarios**
- Correlates metrics, logs, traces, deployment history, and retrieval evidence
- Durable agent workflows using **LangGraph**
- Hybrid RAG with **PostgreSQL + pgvector + full-text search + reciprocal-rank fusion**
- **OpenTelemetry, Prometheus, Loki, Tempo** observability stack
- **Docker, Kubernetes, Helm, Terraform** deployment assets
- **81 backend tests**, 80% coverage
- k6 run: **5,101 requests · 100% success · p95 84.41 ms**
- Human-approved, allow-listed remediation boundaries

[![Code](https://img.shields.io/badge/View_Code-IncidentGraph-111827?style=for-the-badge&logo=github)](https://github.com/Gautam2117/IncidentGraph)

### PGBuddies — Production Full-Stack Marketplace

A live discovery, booking, and management platform for PG accommodation and nearby services.

- Separate renter, property-owner, and admin portals
- Authentication and server-side authorization
- Booking, availability, maps, inquiries, and payments
- PostgreSQL-backed application data
- Redis caching / rate limiting
- Reusable backend API workflows

**Stack:** `Next.js` `TypeScript` `Node.js` `PostgreSQL` `Redis` `Supabase Auth` `Razorpay`
